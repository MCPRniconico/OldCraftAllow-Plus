# ExtraRecipe

**ExtraRecipe** は、Bukkit / Spigot / Paper / Folia 対応の Minecraft サーバープラグインです。

Minecraft に存在しないクラフトレシピを追加できます。

レシピは `config.yml` から個別に有効・無効を切り替えることができます。

## 特徴

- Bukkit API ベース
- Kotlin 製
- Spigot 対応
- Paper 対応
- Folia 対応
- レシピごとの有効 / 無効設定
- Shaped Recipe（定形レシピ）対応
- Shapeless Recipe（不定形レシピ）対応
- NMS 不使用
- データベース不要
- 外部サービス不要
- シンプルな構成
- サーバーのレシピを追加することだけに特化

## 対応環境

| 項目 | 対応 |
|---|---|
| Bukkit | ✅ |
| Spigot | ✅ |
| Paper | ✅ |
| Folia | ✅ |
| Minecraft 1.16.x | ✅ |
| Minecraft 1.17.x | ✅ |
| Minecraft 1.18.x | ✅ |
| Minecraft 1.19.x | ✅ |
| Minecraft 1.20.x | ✅ |
| Minecraft 1.21.x | ✅ |

> 実際の対応バージョンは、使用するビルドおよび Bukkit / Paper API の互換性によって異なる場合があります。
